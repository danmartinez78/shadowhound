# Project Roadmap

## Purpose
Summarize the strategic milestones that guide ShadowHound development and downstream documentation priorities.

## Prerequisites
- Familiarity with the ShadowHound architecture and mission goals.
- Access to the active sprint or milestone tracker.

## Steps
1. Review the roadmap table below for current phase objectives.
2. Link each milestone to its detailed execution plan within the vault.
3. Update status indicators as progress occurs.

### Milestone Summary
| Phase | Focus | Target Outcomes |
|-------|-------|-----------------|
| Phase 0 | Bootstrap | Core ROS 2 packages scaffolded and buildable |
| Phase 1 | Basic Skills | Minimal navigation, perception, and reporting skills validated in simulation |
| Phase 2 | Integrated Autonomy | Mission planner driving hardware-in-the-loop tests |
| Phase 3 | Field Trials | Outdoor autonomy with safety envelope validated |
