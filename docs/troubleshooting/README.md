# Troubleshooting Index

## Purpose
Centralize troubleshooting guides to reduce mean time to recovery across hardware, software, and networking.

## Prerequisites
- Access to telemetry logs or observability dashboards.
- Knowledge of the impacted subsystem.

## Steps
1. Create subsystem-specific troubleshooting playbooks using the page template.
2. Document log file locations and diagnostic commands.
3. Link validated resolutions back to originating incident reports.

## Validation
- [ ] Each incident links to a verified resolution checklist.
- [ ] Diagnostic commands are tested on the current build.
- [ ] Public outputs render without Obsidian-only syntax.
